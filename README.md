# Health Resources in Lebanon – Streamlit App

An interactive page exploring how health facilities (pharmacies, clinics, hospitals, labs and more)
are distributed across Lebanon's governorates and towns, using the Health Resources Lebanon 2023
dataset (Impact Open Data, via linked.aub.edu.lb).

**Live app:** https://health-resources-lebanon-3f4jdnxjvgbiuxw3bj4s5e.streamlit.app/

## Features
- Context and two key insights computed from the data
- Linked drill-down: choose a governorate, then compare towns within it
- Design justifications for each interaction feature

## Run locally
```
pip install -r requirements.txt
streamlit run app.py
```
